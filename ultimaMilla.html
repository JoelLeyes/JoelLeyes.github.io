Última Milla — Proyecto .NET

ASP.NET Core | Blazor | .NET MAUI | AWS | Kubernetes

Plataforma de logística de última milla

Plataforma para gestionar envíos, coordinar repartos y consultar su seguimiento. Integra un backoffice, un portal para comercios, seguimiento público y una aplicación móvil con soporte sin conexión. El despliegue combina contenedores en Amazon EKS, PostgreSQL en Amazon RDS e integración con MongoDB Atlas para el historial de eventos.

Tecnologías y herramientas

  • Aplicaciones: C#, .NET 10, ASP.NET Core, Razor Pages, Blazor, SignalR y .NET MAUI.
  • Datos y mensajería: Entity Framework Core, PostgreSQL, MongoDB Atlas, Redis y RabbitMQ.
  • Infraestructura: AWS EKS, ECR, EC2, ALB, RDS, ACM, Kubernetes y Terraform.
  • Entrega y operación: Docker, GitHub Actions, observabilidad LGTM, HPA y pruebas de carga con k6.
